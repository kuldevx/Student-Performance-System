# Student Performance Analysis System

## Project Overview

The Student Performance Analysis System is a Python-based console application
designed to manage student records and analyze academic performance.

The system allows users to add, view, search, update, and delete student
records. It also calculates performance statistics such as averages,
highest and lowest performers, pass/fail counts, and subject-wise performance.

## Features

- Add student records
- View all students
- Search for a student
- Update student information
- Delete student records
- Analyze class performance
- Generate individual student reports
- Generate class reports
- Generate subject reports
- Load fixed sample data
- Input validation
- Automated program verification

## Technologies Used
